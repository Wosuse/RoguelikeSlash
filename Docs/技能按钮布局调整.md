# 技能按钮布局调整

GameScene和CardLabScene的技能按钮都保存在场景中。运行时脚本只改变状态，不重建按钮。

## 手工布局

1. 退出Play模式，选择场景中的SceneSkillHud组件。
2. Buttons数组顺序为闪、斩、无双；点击引用定位实际按钮。
3. 用RectTransform调整位置、尺寸、锚点和边距。展开子物体可编辑图标、边框、文字、充能点模板；删除不需要的说明后保存场景。
4. Game视图切换目标横屏比例，检查按钮、安全区和摇杆是否重叠。

不要通过重新创建按钮覆盖手工布局。两个场景独立修改；若要复制，将整棵按钮对象复制，包括删改过的子物体，然后重新绑定SceneSkillHud和V06SkillInput的场景引用。V06SkillInput的Owner应指向当前场景的V06Skills，Index为闪0、斩1、无双2。

## 状态表现

- 无双不足时暗淡，圆内水位自下向上积攒；积满后亮起并隐藏水位填充。
- 闪、斩不显示旧黄色矩形进度条。
- 斩外圈表示下一枚剑气的恢复进度，不表示斩持续时间。
- 黄色小圆由斩按钮上的SwordChargeHud控制，数量随剑气容量变化，恢复时逐个点亮。月牙和涟漪共用基础1枚充能；只有剑息增加上限。
- SwordChargeHud的dotTemplate控制小圆样式，startAngle、step和radiusScale调整排列。

SceneSkillHud中的Buttons、V06SkillInput的Owner和Index、SwordChargeHud的Skills和dotTemplate需要对应当前场景。复制后检查这些引用，不恢复用户删掉的说明或子物体。
