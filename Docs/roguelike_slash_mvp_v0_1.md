# 俯视角割草动作游戏 — MVP V0.1 开发规格

> 文档用途：用于 Unity 2D 项目初版开发，可直接提供给 Codex 作为实现计划和验收依据。  
> 版本：MVP V0.1（冷却规则修订）  
> 平台：**手机横屏优先，PC 键鼠用于调试**  
> 本版本核心目标：在一个场景中完成 **移动 → 怪物生成/攻击 → 自动射击 → 主动技能 → 双技能融合 → 受伤/击杀 → 存活/死亡/重开** 的可玩循环。

---

## 1. 游戏概述与范围

### 1.1 游戏定位

- 俯视角 2D、单人、实时战斗、轻度割草。
- 怪物从视野外四面八方不断出现，向玩家移动并尝试攻击。
- 玩家左侧虚拟摇杆控制移动；右侧三个呈三角形排列的技能按钮。
- 玩家持续自动射击附近敌人，主要操作聚焦在三个主动技能的短按、长按、拖拽融合与取消融合。
- MVP 先验证操作是否流畅、战斗是否有乐趣；正式数值成长和美术在后续版本开发。

### 1.2 MVP 必须包含（P0）

- [ ] 玩家移动：PC WASD + 手机左侧虚拟摇杆。
- [ ] 相机跟随玩家；简易无限平面视觉（可使用循环背景，不要求真正无限地图数据）。
- [ ] 三类怪物：**近战追踪型**、**蓄力攻击型**、**远程射击型（发射子弹）**。
- [ ] 怪物从相机视野外生成，追击或进入射击位置，逐步提高刷怪强度。
- [ ] 玩家自动攻击：自动锁敌并发射基础子弹。
- [ ] 敌我双方：生命、伤害、死亡、击退/受击反馈、基本无敌间隔。
- [ ] A 格挡、B 冲刺、C 环形斩：短按与长按。
- [ ] A+B、A+C、B+C：短按与长按，按照第 4 节规格实现。
- [ ] 三角按钮：拖拽融合、融合状态展示、返回取消、释放后拆分、技能冷却可视化；基础技能 8 秒、融合技能 12 秒，均从施放实际结束时开始计时。
- [ ] 计时、击杀数、血量、死亡面板、重新开始；一局至少支持 5 分钟。
- [ ] 简易音画反馈；不要求正式美术、动画和复杂 VFX。

### 1.3 明确不做（MVP 范围外）

- 肉鸽三选一升级、经验掉落与升级池（**后续**）。
- 元素附着、元素反应（后续）。
- 三技能融合终极大招（后续；架构预留组合 ID 即可）。
- 召唤物主动技能（后续可作为自动攻击肉鸽分支）。
- 局外养成、背包、商店、关卡随机生成、联网、Boss、多角色、存档。

### 1.4 完成定义（Definition of Done）

无需开发者操作编辑器，启动游戏后可以：移动、自动射击、遭遇三类怪物及**远程飞行子弹**、使用全部六个按钮形态（3 基础 + 3 双融合）的短/长按、死亡、重开。MVP 可以通过一整局 5 分钟存活测试，没有明显的输入卡死、持续技能无法退出、远程子弹残留或对象池泄漏。

## 2. 场景与核心战斗循环

```text
进入游戏
  ↓
玩家出生 / 初始化 HUD / 开始计时
  ↓
怪物从视野外随机刷新
  ├─ 近战怪：追击并接触攻击
  ├─ 蓄力怪：接近 → 明显前摇 → 冲撞/挥击
  └─ 远程怪：保持距离 → 瞄准前摇 → 发射子弹 → 再定位
  ↓
玩家自动射击 + 移动 + 手动技能与融合
  ↓
敌人受到伤害 / 死亡 / 计入击杀数
  ↓
随存活时间提高怪物数量与组合
  ↓
玩家 HP ≤ 0 → Game Over → 重新开始
```

**场景建议：** 单个 `GameScene`，简易网格地面，玩家初始在世界坐标原点，Camera 正交跟随，怪物随机从镜头外安全边界生成。第一版只需要持续生存，不需要终点出口。

## 3. 玩家、自动攻击和通用战斗规则

### 3.1 玩家移动

- 使用 `Rigidbody2D`（动态或运动学方案二选一，项目内保持一致）进行移动，避免直接用 Transform 穿墙/穿怪造成无法控制的碰撞。
- 左摇杆控制二维方向；PC 通过 WASD 输入同一移动向量。
- 默认 8 方向连续移动，不需朝向鼠标；非定向技能以玩家为中心释放。
- 冲刺使用统一 `DashMotor`，具备方向、距离、时长、是否可穿怪等可配置参数。

### 3.2 自动攻击（固定的基础输出）

- 每隔固定时间搜索攻击范围内最近的有效敌人。
- 朝目标当前位置发射一枚玩家子弹；不需要手动瞄准。
- 没有目标时暂停发射，不积累大量待释放子弹。
- 玩家子弹命中敌人：造成固定伤害、产生命中反馈，默认只命中一个目标。
- 自动攻击在角色长按、融合、守备时仍可运行；若状态明确禁止攻击，需在状态配置中指定。
- **召唤物不进入本版**；未来可以作为自动攻击武器分支，而不是第四个主动技能。

### 3.3 通用伤害系统

统一处理以下事件：`OnBeforeDamage` → 防御/闪避/格挡判定 → `ApplyDamage` → `OnDamageTaken` / `OnBlocked` → 死亡判定。

建议最少区分：

- `DamageSource`：玩家子弹、敌方子弹、普通碰撞、蓄力攻击、技能斩击。
- `Faction`：Player / Enemy（避免同阵营误伤）。
- `AttackInstanceId`：一次攻击的唯一 ID，用于防止同一剑气多帧碰撞而重复计伤。
- `DamageAmount`、`Knockback`、`Direction`、`CanParry`、`CanPerfectDodge`。

**MVP 判定原则：**

1. 玩家/怪物受伤有短暂受击保护，避免同一个重叠碰撞体每帧扣血。
2. 玩家子弹与敌方子弹必须是不同阵营；碰撞过滤不应把所有子弹都当作玩家攻击。
3. A 格挡、A+C 闪避必须在扣血之前判定，不能先扣血再回滚。
4. 允许同一个敌人被不同斩击攻击，但同一次斩击对同一敌人的重复命中遵循该技能明确的次数/间隔规则。

## 4. 主动技能与融合规格（MVP 核心）

### 4.1 统一技能表

| 按钮 | 短按 | 长按 | 战斗价值 |
|---|---|---|---|
| **A 格挡** | 短窗口完美弹反；成功触发反击 | 按住防御，承受较低伤害，并积累反击；松开结算 | 精准防御 |
| **B 冲刺** | 沿指定方向快速位移 | 进入方向瞄准，松开造成一次矩形范围伤害 | 机动/定向打击 |
| **C 环形斩** | 立即进行一次快速环形斩 | 按住持续旋转，对周围怪物周期造成伤害 | 近身输出 |
| **A+B** | 防御冲锋，冲刺过程中具有弹反窗口 | 举盾准备，松开沿指定方向释放矩形反击冲击波 | 突围/反击 |
| **A+C** | 闪避；普通获得 2 次、极限闪避获得 4 次免费环形斩 | 守备反击，受击触发环形斩，最多 3 次或 5 秒；退出自动补完剩余次数 | 反应/守备 |
| **B+C** | 先冲刺到终点，**再**从原起点沿路径推进两道弧形斩击 | 原地瞄准并释放向前移动的大范围半月斩 | 清线/爆发 |

> A / B / C 是按钮编号，不强制代表 UI 上固定方位；三个按钮保持三角布局。

### 4.2 A：格挡

**短按：**

- 快速开启短暂完美弹反窗口，抵挡可弹反的敌方攻击（包括远程怪子弹）。
- 成功弹反时，触发近身反击反馈；对弹丸可将其销毁并生成一枚朝射手方向飞行的反射弹，或直接返回伤害（MVP 推荐直接生成玩家阵营反射弹）。
- 未命中攻击时不产生主动伤害；完美弹反判定窗口结束且反击动作结算后，进入冷却（不要求等待独立反射弹飞行结束）。

**长按：**

- 按住进入防御状态，降低承受的伤害，移动速度降低。
- 受到攻击时积累反击能量；松开时结算一次范围反击（反击强度有上限）。
- 与 A+C 长按不同：A 更偏向纯防御，A+C 则在守备期间直接用斩击反击。

### 4.3 B：冲刺

**短按：**

- 采用左摇杆方向；无方向输入时采用角色上次有效移动方向。
- 冲刺时间和距离固定，可穿过普通敌人，但不穿越不可通行障碍（MVP 可无障碍）。
- 是否包含短暂无敌帧做成配置项；首版建议只提供非常短的受击保护，避免远程弹幕使冲刺必定受伤。

**长按：**

- 进入方向瞄准状态（右手在技能按钮外滑动调整方向），松开释放矩形攻击。
- **长按 B 不让角色移动**，形成与短按冲刺的明显区别。

### 4.4 C：环形斩（共享攻击定义）

**短按：** 一次立即生效的环形斩，对范围内敌人造成伤害。  
**长按：** 持续旋转；按住期间按固定间隔造成环形斩伤害，移动速度适度下降；松开结束。

将环形斩实现为通用攻击定义 `RingSlashDefinition`：伤害、范围、命中效果、暴击/击退配置、一次攻击实例的命中频率由它统一管理。C 和 A+C 调用相同攻击定义；未来肉鸽强化作用到这个定义上。B+C 的弧形/半月形斩击**继承斩击伤害与通用命中效果，但几何碰撞和运动轨迹由融合技能负责**。

### 4.5 A+B：防御冲锋

**短按：** B 的冲刺 + A 的短窗口格挡/弹反，冲刺过程中可弹反敌人具有明显攻击判定的近战招式和远程子弹。  
**长按：** 进入定向准备/防御，松开时向选定方向释放一次矩形反击冲击波。防御成功可增强冲击波，但没有成功防御也能释放基础版本。

### 4.6 A+C：闪避反击与守备反击（高优先级实现）

**短按完整规则：**

1. 点击融合按钮，玩家向移动/选定方向闪避。
2. 若未触发极限闪避：进入**普通反击态**，获得 **2 次免费环形斩**；无额外敌人时缓、无额外伤害免疫。
3. 若触发极限闪避：进入**极限反击态**，敌人行动/敌方弹丸明显时缓，获得 **4 次免费环形斩**，反击态期间玩家免疫伤害。
4. 特殊反击态中，同一个融合按钮临时切换为环形斩按钮；每点击一次消耗 1 次，调用 `RingSlashDefinition`。
5. 最多持续 **3 秒**；次数耗尽或时间到，反击态与最后一记斩击结算完成后，A、C 恢复为两个基础按钮，**此时同时开始 12 秒融合冷却**。
6. 普通闪避可以拥有闪避动作本身的短暂无敌帧，**但普通反击态不能获得额外免疫**。
7. **极限闪避判定：** 闪避的规定窗口内，成功躲过一次原本会命中玩家、具有明确攻击判定的招式/敌方弹丸；不能仅靠走近任何接触怪就反复刷奖励。

> 时间缩放：只减慢敌人的移动、攻击前摇/攻击动作以及敌方弹丸速度；**不直接修改全局 `Time.timeScale`**，保持玩家操作、UI 倒计时、融合状态和玩家子弹正常运行。

**长按完整规则：**

1. 按住进入**守备状态**：移动速度下降，受到伤害下降。
2. 每次有效受击触发格挡并**自动释放 1 次环形斩**；总共拥有 **3 次环形斩额度**。
3. 同一帧的多次攻击、接触伤害需要防止连续耗尽次数；受击触发设置最小间隔。
4. 持续守备最长 **5 秒**。
5. 玩家**主动松开**时，剩余环形斩**自动按顺序全部释放**，然后退出。
6. **5 秒到期**也自动释放剩余次数；若已触发 3 次则立即退出。
7. 自动补放不是同一帧同时伤害，而是依次触发斩击事件与动画；补放期间不能再次进入守备。
8. 自动补放的最后一记环形斩结算完成后退出，恢复 A、C 按钮，并**从该时刻同时开始 12 秒融合冷却**；不能在松手时提前启动 CD。
9. MVP 守备格挡定义：削减伤害并触发斩击，**不是完全免疫全部伤害**；数值可调。

**状态机建议：**

```text
FusedReady
  ├─ ShortPress → Dodging
  │   ├─ Normal → CounterReady(2, duration=3s)
  │   └─ Perfect → CounterReady(4, duration=3s, enemySlow, damageImmune)
  │        └─ 次数耗尽 / 超时 → FinishLastSlash → RestoreButtonsAndStartCooldown
  └─ LongHold → Guarding(max=5s, slashQuota=3)
      ├─ OnValidHit → Block + RingSlash + quota--
      ├─ quota==0 → FinishLastSlash → Exit
      ├─ Release → AutoFinishRemainingSlashes → Exit
      └─ Timeout → AutoFinishRemainingSlashes → Exit

Exit → 当前技能执行真正结束 → 恢复 A、C 按钮 → A、C 同时开始 12s CD
```

### 4.7 B+C：冲刺追击与前移半月斩

**短按：**

1. 记录 `dashStart`、方向和实际冲刺终点 `dashEnd`。
2. 玩家先完成整段冲刺；**冲刺过程中不生成两道弧形剑气**。
3. 角色抵达终点后，从**原冲刺起点**生成两道弧形斩击。
4. 两道剑气沿 `dashStart → dashEnd` 的方向向前推进，分别覆盖路径两侧/两个弧形区域。
5. 每一道剑气按独立 `AttackInstanceId` 命中；视觉与判定同步，剑气到达终点或超时回收。
6. 即使玩家被阻挡提前结束冲刺，仍以实际的 `dashEnd` 计算追击路径，避免超出有效位移。

**长按：** 角色留在原地完成定向瞄准，松开生成一个**向前移动的大范围半月形斩击**，范围较大但不移动玩家。

### 4.8 三技能终极融合

- **MVP 不实现**。
- 不在界面展示无法使用的终极按钮。
- 融合数据结构保留 `skillIds` 集合的扩展可能即可，不提前实现复杂大招资源与能量系统。

### 4.9 冷却 CD 规则（MVP 强制实现）

**统一数值：**

- **A、B、C 基础技能**：每次短按或长按释放完成后，对该技能启动 **8 秒 CD**。
- **A+B、A+C、B+C 双技能融合**：每次短按或长按释放完成后，对参与融合的**两个基础技能分别启动 12 秒 CD**，起点相同；未参与融合的第三个技能不受影响。
- **按住技能、瞄准、冲刺中、守备中、持续旋转中、特殊反击态中、自动补斩中、主斩击尚在运动中，都不计 CD**。
- **拖拽完成融合、维持融合状态或点击返回取消融合**：均不消耗技能，也**不触发 CD**。正在 CD 的基础技能不能参与新的融合。
- **CD 仅在施放完成时开始**；禁止在触摸按下、松手、融合成功、冲刺开始或生成攻击体时抢先启动。

**“技能释放结束”的统一判定：**

| 技能类型 | 开始计算 CD 的时刻 |
|---|---|
| A 短按 | 弹反窗口及对应即时反击动作结束（飞走的独立反射弹不阻塞） |
| A 长按 | 松手，且防御结束、蓄积反击结算完成 |
| B 短按 | 冲刺动作到达实际终点/被阻挡而结束 |
| B 长按 | 松手发出矩形攻击，矩形攻击判定与动作完成 |
| C 短按 | 本次快速环形斩判定与动作结束 |
| C 长按 | 松手，且本次旋转斩最后一个伤害结算完成 |
| A+B 短按 | 防御冲锋的冲刺和弹反判定结束 |
| A+B 长按 | 矩形反击冲击波的主要攻击判定结束 |
| A+C 短按 | 2/4 次反击斩用完，或 3 秒超时，且当前斩击结算完成；结束特殊状态之后 |
| A+C 长按 | 守备结束，**剩余环形斩自动全部放完**，最后一击结算完成之后 |
| B+C 短按 | 冲刺到终点，**然后两道弧形斩从起点推进并全部结束**之后 |
| B+C 长按 | 发射的移动半月斩完成路径或达到生存时限并结束主要攻击判定之后 |

**实现约束：**

1. 技能状态统一为 `Ready / Casting / Active / Finishing / Cooldown`；只有完整执行进入 `Finished` 事件时，才从 `Finishing` 转为 `Cooldown`。持续技能不得在 `Active` 时提前开始计时。
2. `SkillCooldowns` 用绝对结束时间 `readyAt = now + duration` 记录 CD；UI 根据剩余时间显示进度。倒计时使用不受敌人时缓影响的玩家侧时间，游戏整体暂停时停止计时。
3. 技能触发后因受控/打断而提前停止时，先完成清理，再视为该次技能结束并启动对应 CD；死亡/重开则统一重置状态与 CD，不残留旧计时器。
4. 一次技能执行只能发出一次 `SkillFinished`，防止连击次数耗尽、超时、松手同帧发生时重复启动 CD。
5. 远程怪物与自动攻击的 CD 独立于**玩家主动技能 CD**，不应用这里的 8 秒/12 秒配置。

**示例：** A+C 长按守备 2 秒，守备期间触发 1 次斩击；松手后自动补放剩余 2 次，直到最后一斩结束才开始 A、C 各 **12 秒**冷却。B+C 短按也必须等两道弧形斩均结束再对 B、C 开始 **12 秒**冷却。

## 5. 操作与三角形 UI

### 5.1 布局

- 左下角：虚拟摇杆。
- 右下角：A、B、C 三个圆形按钮，呈紧凑三角形布局；颜色或图标明确区分防御、冲刺、环形斩。
- 中上方：HP、存活时间、击杀数。
- 融合后：**原来的两个按钮合并为一个新按钮**，第三个按钮继续保留；出现一个较小的**返回/取消融合**按钮。
- A+C 特殊反击状态：融合按钮显示 `2/4` 等剩余次数及 3 秒倒计时。
- CD 状态：按钮蒙层/环形倒计时；只有符合释放条件的技能可用。**施放过程不走 CD；技能实际结束后才启动倒计时。**

### 5.2 输入识别优先级

**必须先解决短按、长按与拖拽之间的冲突。** MVP 推荐：

1. 触摸开始时记录起点与时间。
2. 在手指移动超过阈值时，优先判断拖拽方向是否指向其他技能按钮；确认为融合手势时，不触发单技能。
3. 未触发融合时：短按由快速点击释放；长按达到阈值进入持续/瞄准状态，松手结算。
4. A 的弹反对延迟非常敏感：首版将其点击阈值设得尽量低，记录输入至弹反判定开始的延迟；若点击松手触发手感不佳，再单独设计按下即判定、拖拽不误触的方案。
5. 已进入长按技能时不允许再拖拽融合；必须松开该次施法后再融合。
6. 融合阶段不消耗技能 CD；**点击返回无冷却消耗**。
7. 融合技能的**完整执行结束后**（并非按下、松手或生成攻击物时），恢复参与融合的两个基础按钮，并让这两个按钮**同时从 12 秒开始倒计时**；未参与融合的第三个技能 CD 不受影响。
8. 被控制、死亡、暂停或切场景时，必须安全取消持续技能并清理 UI 状态。

> 初始测试阈值建议：短按判定约 0.20 秒，长按触发约 0.25 秒；手指移动阈值使用像素密度适配。此处是**可调的原型参数**，不是最终设计。

### 5.3 PC 调试操作

- WASD：移动。
- 鼠标左键：操作右侧技能按钮，含长按与拖拽。
- 可额外提供 A/B/C 独立键位的快捷施放（如 J/K/L），但**不能绕过触控操作流程的测试**。
- `Esc`：暂停/恢复。
- 开发构建：显示状态机状态、CD、敌人数量、活跃子弹数量、最近一次受击来源。

## 6. 怪物系统（包含远程发射子弹）

### 6.1 怪物类型

| 类型 | 移动行为 | 攻击行为 | MVP 主要验证点 |
|---|---|---|---|
| **MeleeChaser** 普通追踪怪 | 持续靠近玩家 | 近距离碰撞/接触攻击；独立攻击间隔 | 怪潮密度、自动射击、普通技能清怪 |
| **TelegraphStriker** 蓄力攻击怪 | 进入攻击距离后停顿 | 明显前摇后突进或挥击，有明确可弹反时机 | A 完美弹反、A+C 极限闪避 |
| **RangedShooter** 远程射击怪 | 尝试保持与玩家一定距离；过近后撤/侧移 | **面向玩家瞄准，经过前摇后发射一枚飞行子弹** | 远程威胁、走位、弹反子弹、闪避与时缓 |

### 6.2 远程射击怪：详细行为

**初版只做最简单、可读的单发直线子弹，不做散弹或追踪弹。**

```text
Spawn
  ↓
SeekRange：接近至理想射程
  ├─ 太远 → 接近玩家
  ├─ 太近 → 远离玩家 / 轻微侧移
  └─ 合适 → 减速/停下
  ↓
Aim：显示瞄准方向和预警（约 0.5~0.7 秒）
  ↓
Fire：发射 1 枚 EnemyProjectile
  ↓
Recover：短暂攻击后摇 / CD
  ↓
SeekRange（循环）
```

**子弹规则：**

- 子弹从敌人的发射点生成，沿**发射瞬间锁定的方向**直线移动；玩家移动后不追踪。
- 子弹携带：`Faction=Enemy`、伤害、速度、碰撞半径、最大存活时间、发射者引用或 ID。
- 命中玩家时走统一伤害管线；支持被弹反、被闪避、被守备减伤。
- A 完美弹反远程弹丸时：敌方弹丸停止造成伤害，生成反射弹，朝原射手或弹丸反向飞行；反射弹归属 `Player`。
- A+C 极限闪避时：能利用即将命中玩家的子弹触发判定；极限反击期间敌方子弹也受到时缓影响。
- 子弹撞击玩家、超过有效生存时间、离开足够远的战斗区域时回收到对象池。
- 子弹不可因为玩家移动到同一坐标附近而重复扣血；不得打中自己阵营怪物（MVP 不做敌方友伤）。
- 射击前摇必须有明显视觉反馈，例如地面瞄准线/红色扇形警告，避免玩家无法判断何时闪避。

**远程攻击与格挡/闪避的最小联动验收：**

1. 不移动玩家时，远程怪会完成瞄准并发射，子弹命中会扣血。
2. 玩家移动躲开飞行路径时，子弹继续沿原方向飞行，不会突然拐弯。
3. A 成功弹反该子弹后，玩家不受该次弹丸伤害，子弹被销毁或转为反射弹。
4. A+C 短按在正确时机避开子弹，可以进入 4 次斩击的极限反击态；普通闪避仅获得 2 次。
5. A+C 长按守备时被子弹命中，会按配置减伤并触发一次环形斩（遵循反击触发间隔）。

### 6.3 怪物生成规则

- 依据相机正交可见矩形外扩 `spawnMargin`，随机选择四边中的一边并在边上随机选点。
- 出生位置必须在**当前屏幕外**，避免怪物凭空出现在玩家眼前。
- 地图无限平面的情况下，以玩家/相机为参考生成，不使用固定地图边界。
- 逐步增加总刷新速率与特殊怪占比，但始终限制活跃数量；**远程怪单独设上限**，避免子弹数量过密。
- 新怪物与玩家保持最小出生距离；死亡或距离玩家过远时可回收。
- 由刷怪配置决定怪物种类权重；不要把生成节奏写死在具体怪物脚本中。

### 6.4 起步刷新节奏（可配置，非正式平衡）

| 存活时间 | 近战怪 | 蓄力攻击怪 | 远程怪 | 全局建议 |
|---|---|---|---|---|
| 0:00–0:30 | 主要敌人 | 不出现 | 不出现 | 约每秒 1–2 只 |
| 0:30–1:30 | 主要敌人 | 少量出现 | 少量出现 | 引入攻击前摇和弹丸 |
| 1:30–3:00 | 持续出现 | 中等占比 | 中等占比 | 约每秒 2–4 只 |
| 3:00–5:00 | 大量出现 | 适当增加 | 适当增加 | 按性能上限调节 |

初始并发上限：`MaxEnemies = 100`，`MaxRangedEnemies = 12`，`MaxEnemyProjectiles = 80`，`MaxPlayerProjectiles = 80`。可以根据设备表现逐步调低或提高；这不是必须达到的实际同屏数量。

- [ ] A+B：弹反冲锋、矩形反击。
- [ ] B+C：冲刺后才从起点发出双弧形斩、长按移动半月斩。

**验收：** 融合与拆分无误；B+C 必须先完成冲刺，再生成从起点向终点推进的剑气；能在怪潮中多次重复操作。

### M5 — A+C 特殊状态

- [ ] 普通闪避 → 2 次免费环形斩（3 秒有效，无额外时缓/免疫）。

- [ ] 与远程子弹的弹反、闪避、守备判定联调。

**验收：** 不出现免费斩击次数错误、时缓结束后敌人不恢复速度、按钮无法拆分、死亡后残留守备状态等问题。

### M6 — 一局可玩与性能收尾

- [ ] 设计简单的 5 分钟刷新曲线，完成可重玩的战斗循环。
- [ ] 限制同屏敌人与敌方子弹数；压力测试对象池。

- [ ] 在至少一种桌面分辨率、一种手机比例下完成全流程测试。

**验收：** 一局可完整玩到死亡或 5 分钟；重开后状态重置；没有持续严重掉帧、技能按钮卡死、弹丸不回收。

## 10. 关键测试用例

### 10.1 输入和融合

- [ ] A/B/C 短按与长按识别正确，拖到其他按钮不会误触原技能。
- [ ] 点击“返回”后重新显示基础按钮，CD 不消耗。
- [ ] 任意融合技能**完整结束后**，仅参与融合的两个基础按钮从同一时刻开始 **12 秒 CD**，第三个按钮不受影响。
- [ ] 基础技能 CD 固定 **8 秒**、融合技能 CD 固定 **12 秒**，均在施放完成前保持未计时。
- [ ] 融合后只点击返回（未释放），不新增任何 CD；处于 CD 的技能不可融合。
- [ ] 无法在正在使用持续技能时进入错误的融合状态。
- [ ] 游戏暂停/死亡时，所有长按和瞄准状态都正常退出。

### 10.2 近战和远程交互

- [ ] 远程怪在合适距离瞄准并**实际生成一枚可见、可碰撞的子弹**。
- [ ] 远程怪不会每帧射击、超出 CD 频率或在死亡后继续发射。
- [ ] 子弹命中扣血；移动躲开后不会凭空命中；撞击后正确回收。
- [ ] A 成功弹反可弹反远程子弹，反射弹不会再次伤害玩家。
- [ ] A+C 普通闪避：2 次斩击、无额外时缓、反击态不免疫伤害。
- [ ] A+C 极限闪避：4 次斩击、3 秒时缓，敌方子弹同步减速，结束后恢复。
- [ ] A+C 长按：远程子弹命中会按配置减伤、触发斩击；松开自动补完剩余次数。

### 10.3 技能时序与数值

- [ ] B+C 短按在玩家到终点**之前**不会出现两道弧形斩。
- [ ] B+C 弧形斩从原始冲刺起点朝实际终点移动。
- [ ] B+C 短按必须在**两道弧形斩全部消失/命中结算**后才触发 B、C 的 12 秒 CD。
- [ ] A+C 短按在免费斩击次数用尽或 3 秒结束且最后一击结算后才进入 12 秒 CD。
- [ ] A+C 长按在守备 5 秒到期或主动松手并**自动补完剩余斩击**后才进入 12 秒 CD。
- [ ] C 长按持续旋转期间不跑 CD，松开并结束当前斩击后才开始 8 秒 CD。
- [ ] C / A+C 的环形斩公用攻击定义与数值，未重复实现伤害逻辑。
- [ ] 一次攻击对同一敌人不会因多帧 Overlap 意外结算几十次伤害。
- [ ] 所有持续技能都有松手、超时、受控/死亡时的退出路径。

### 10.4 压力与重开

- [ ] 怪物达到上限后不会无限实例化。
- [ ] 敌方子弹与玩家子弹数量受控；远距离弹丸定期回收。
- [ ] 对象池回收后不继承旧弹丸方向、阵营、伤害和发射者引用。
- [ ] Retry 后无旧敌人、旧子弹、旧时缓、旧 CD、旧融合按钮状态。

## 11. 给 Codex 的实施约束

1. **按 M1 → M6 逐步开发**，每个阶段确保运行与验收后再进入下一阶段；不要一次性堆全部功能。
2. 优先交付可运行的最小改动，简易几何素材即可，不因缺少美术阻塞实现。
3. 远程怪与子弹属于 MVP 必须项，不能只预留接口或只画预警线而不真正发射子弹。
4. 对单帧碰撞、弹反与闪避事件，采用统一伤害和事件顺序；确保触发和扣血不会互相矛盾。
5. 斩击共享**伤害与命中规则**；斩击几何与运动行为允许不同，以支持后续肉鸽继承。
6. 核心参数应集中可调；主动技能 CD 在本版固定为基础 **8 秒**、融合 **12 秒**，均从技能实际结束时开始；其余数值为初始测试值。
7. 不提前实现未要求的肉鸽升级、元素反应、三技能大招、复杂装备系统。
8. 每个阶段附上：新增/修改文件、可操作的测试步骤、已知限制、未完成项。
9. 如实现细节有冲突，优先保证：**技能手感与状态正确 → 远程子弹/碰撞正确 → 刷怪性能 → 美术效果**。
10. 允许在不改变外部行为的前提下简化类数量，不为追求架构而增加不必要的抽象。

- **V0.3 三技能终极大招**：在两技能融合操作基础上增加第三技能融合与资源消耗。
