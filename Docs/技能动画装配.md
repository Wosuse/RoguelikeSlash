# 技能动画装配

GameScene 与 CardLabScene 均已绑定同一份动画配置：`Assets/Game/Data/Animation/DefaultSkillAnimations.asset`。

## 对应关系

| 触发 | 角色动画 | 播放规则 |
|---|---|---|
| 短按闪，无方向输入 | dodge，10帧 | 后退闪，保持原朝向 |
| 短按闪，有方向输入 | forward-dodge，10帧 | 朝输入方向闪，使用向前闪动画 |
| 长按闪（未持有写意） | run，5帧 | 移动时循环，步频跟随实际移动速度 |
| 短按斩、写意自动斩 | slash，10帧 | 按斩生效时长播放，写意自动斩仍可移动 |
| 持有蓄势后长按斩 | charge-enter 4帧 → 稳定蓄力姿势 | 蓄力期间不可移动；进入后保持末帧，松开或蓄满转为旋转，避免体型反复切换 |
| 无蓄势时长按斩 | spin，10帧 | 直接旋转，不等待蓄力循环 |
| 月牙 | crescent，3帧 | 银白月牙朝释放方向飞行 |
| 涟漪 | ring，3帧 | 银白圆环以释放位置为圆心扩张 |

无双连招也会根据实际释放的闪、斩、环斩显示对应动作。写意不替换成冲刺奔跑，以写意实际自动斩和普通移动为准。

## 调参入口

在Project中选择上述.asset，展开对应动作：

- 序列帧：可替换、增减、调整顺序。
- 每帧秒数：控制奔跑循环、蓄力进入/保持和剑气流动速度。短闪、挥剑、旋转会适配技能生效时间，这三个动作的每帧秒数用于装配台预览。
- 播放倍率：默认1。非循环动作加快后会停留在末帧，直到技能结束。
- 显示倍率、显示偏移：只调整外观，不改变命中范围、移动速度或位移距离。角色默认显示倍率1.32、向上偏移0.075，用于对齐现有待机画布。
- 月牙基础宽高、圆环外径显示倍率：调整剑气显示大小；圆环始终跟随实际扩散距离。
- 剑气颜色倍率：默认白色，保留银白素材原色。

主角外观的 ArenaPlayerAnimation 与战斗/主动技能/V06Skills 都引用同一个配置，不需要分别填两套帧。闪避、斩击的音效仍在 V06Skills 原有 dodgeSound、slashSound 槽位；没有新增重复的音效配置。

CardLab的动画装配台可在State选择短按闪避、冲刺奔跑、短按斩、进入蓄力、保持蓄力、旋转斩、月牙剑气或圆环剑气。可用Replay从头预览；这些预览读取同一配置。旧Fps字段仅影响原有的待机/移动/攻击自定义序列。

动作图片在 `Assets/Game/Art/Animations/Player`，剑气在 `Assets/Game/Art/Effects/SwordEnergy`。运行素材只保留这一份；相同的蓄力准备帧由多个动作复用引用。原画参考在ArtSource/References，提示词汇总在ArtSource/Prompts.json。

向前闪的每帧秒数、播放倍率、显示倍率和偏移已复制当前后闪配置，之后可在「短按闪：向前闪」独立调整。短闪开始后保持本次选择的动画，不会因中途松开摇杆切换成后闪。

## 技能过程与收尾节奏

前闪、后闪、短斩、旋转斩均为10张不同姿势，原有5张关键帧之间补入5张新中间帧。四组的播放倍率为1，按已有技能生效时长播放完整动作，整体尺寸与偏移沿用配置。普通奔跑循环不受本次补帧影响。

短斩每帧时长权重为0.3、0.7、0.6、0.9、0.5、0.5、0.5、0.375、0.375、0.25。前7帧占80%，最后3帧占20%，末帧占5%。每帧秒数0.025，使装配台的10帧预览仍为0.25秒。

前后闪的权重集中在中段位移姿势；旋转斩集中在转身与挥剑阶段，开始和结束较短。每帧权重越大停留越久，不改变总时长。权重数组留空或长度不匹配时恢复均匀播放。

蓄力保持直接复用进入动作的末帧，不再循环大小不一致的旧姿势。该帧也作为旋转第一帧，文件在spin/spin-01.png；三个配置共享同一张图片，不额外复制素材。每张补帧使用相同画布和脚底基点，每组按固定比例装配，不按各帧包含刀剑的总包围盒高度分别缩放。

素材由内置image_gen补画，生成提示词保存在ArtSource/Prompts.json的skill_inbetweens_2026_11_22字段。只将切好的运行帧装入Assets，不在项目中保留重复拼图和预览。

## 月牙实际判定

在「成长/强化卡配置/月牙 → 效果调参」控制「月牙判定跟随动画大小」，两场景默认开启。命中总宽度=DefaultSkillAnimations的月牙基础宽高Y×月牙显示倍率，飞行路径两侧各取一半。动画显示和判定共用同一尺寸计算，放大图片会同步扩大伤害与剑气强化消弹宽度。说明同步显示当前有效宽度。

关闭同步后才显示手动命中总宽度，保留此前手动值。图片的X控制沿飞行方向的视觉厚度，Y控制展开高度；当前碰撞仍是沿飞行路径的胶囊式判定，不是按月牙透明轮廓逐像素检测。

飞行速度、距离为两种剑气共用；最后一步不会越过设定距离。旧Sword Sprite和Writing Duration字段已删除；月牙/涟漪的副参数、持续时间、范围覆盖，以及蓄势无效的通用字段不再显示。

## 后闪方向与短斩刀光

无方向输入时，后闪始终向角色当前左右朝向的反方向移动，不使用最后一次上下移动方向；有摇杆输入时仍按输入方向前闪。左右朝向与实际显示的翻转状态同步。

短斩使用实体月牙图片的蓝白刀光，每次挥斩只在释放位置前方显示一道固定月牙，再快速淡出，不跟随角色或剑移动，不再显示短斩拱形线条。参数在战斗/主动技能/V06Skills的「短按斩：蓝白月牙刀光」：大小、距离、起手延迟、显示时间、淡出时间、颜色、独立贴图和材质。默认复用现有月牙素材的首帧，月牙剑气的飞行参数不影响此刀光。写意自动斩也使用此效果，环形斩继续使用原有完整环扫。

刀光的「出现延迟（秒）」从斩释放时开始计时，仅影响显示；「出现距离（斩半径倍数）」控制刀光中心到释放位置的距离。摇杆拉动时，手动斩及刀光沿摇杆方向生成（支持上下、斜向）；写意自动斩沿最近敌人方向。方向和位置在释放时固定，之后只变色、淡出。

环形斩改为蓝白刀刃环扫，亮白刃口、蓝色透明拖尾，环扫结束快速淡出。配置位于战斗/主动技能/V06Skills → 环形斩：蓝白刀光环，可调整刀光宽度、环扫时间、淡出时间、颜色与材质。宽度默认 1 世界单位，刀光外沿取当前环形斩伤害半径；表现独立于涟漪剑气。

刀光描边：短按斩 → 蓝白月牙刀光下可调「黑色描边宽度（贴图像素）」「边缘收紧阈值」「描边颜色」；默认材质使用 BladeOutline 锐化描边着色器，自定义材质则由自定义材质负责描边。环形斩 → 蓝白刀光环下可调「黑色描边宽度（世界单位）」「描边颜色」；蓝白色带使用硬边，避免透明渐变造成模糊。两种刀光描边均随效果淡出，不影响伤害判定和剑气。

环形刀光仅保留外侧黑色描边，内侧直接使用蓝色刀光，不加黑边；Inspector 对应「外侧黑色描边宽度（世界单位）」。
