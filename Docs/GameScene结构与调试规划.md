# GameScene 结构与调试规划

现有 `ArenaPrototype.*.cs` 属于同一个 `partial class`，所以所有序列化参数集中在 Arena 的同一个组件。界面通过 `OnGUI()` 绘制，Scene 中没有可选中的按钮、血条和摇杆。本规划将技能参数迁移到各自的组件，并将 UI 保存为场景中的 Canvas 对象。

## GameScene 对象层级

```text
GameScene
├─ Main Camera
├─ EventSystem
└─ Arena
   ├─ 系统_Systems
   │  ├─ 对局流程
   │  ├─ 输入管理
   │  ├─ 技能组合管理
   │  └─ 音频管理
   ├─ 场景_World
   │  ├─ 地面
   │  ├─ 网格
   │  └─ 边界
   ├─ 玩家_Player
   │  ├─ 功能（移动、生命与受伤、自动射击）
   │  ├─ 外观（本体、受伤表现）
   │  └─ 特效挂点
   ├─ 敌人_Enemies
   │  ├─ 生成管理
   │  ├─ 追击敌人配置
   │  ├─ 冲锋敌人配置
   │  └─ 射击敌人配置
   ├─ 技能_Skills
   │  ├─ 按钮A_防御
   │  ├─ 按钮B_冲刺
   │  ├─ 按钮C_斩击
   │  ├─ 按钮A+B
   │  ├─ 按钮A+C
   │  └─ 按钮B+C
   ├─ 界面_UI [Canvas]
   │  └─ 安全区域
   │     ├─ 状态栏（生命条、时间、击杀数）
   │     ├─ 移动摇杆
   │     ├─ 技能按钮区域（A、B、C、A+B、A+C、B+C、取消组合）
   │     ├─ 拖拽显示层
   │     ├─ 战斗提示
   │     └─ 结算面板
   └─ 运行时_Runtime
      ├─ 敌人实例
      ├─ 玩家子弹
      ├─ 敌人子弹
      └─ 技能特效实例
```

## 技能对象与脚本

每个技能使用相同层级。以 A 为例，脚本名称暂定。

```text
按钮A_防御 [SkillBinding]
├─ 功能 [GuardAbility]
├─ 外观
│  ├─ 按钮界面 [SkillButtonStyle]
│  ├─ 点按防御 [GuardTapVisual]
│  ├─ 持续防御 [GuardHoldVisual]
│  ├─ 格挡成功 [ParryVisual]
│  └─ 防御波 [GuardWaveVisual]
├─ 音效 [SkillAudio]
└─ 调试 [SkillDebug]
```

功能组件按点按、长按、判定和冷却等用途分组。外观子对象对应独立表现，按钮界面组件保存图标、颜色、文字及实际 UI 引用。判定范围由功能组件提供，外观读取同一数值。音效组件配置各阶段的音频。调试组件只读显示当前阶段和剩余冷却，并提供范围预览及测试入口。

## Inspector 调整表

| 技能 | 功能参数 | 外观子对象 |
| --- | --- | --- |
| A 防御 | 点按冷却、格挡窗口、长按上限、减伤、防御波伤害／速度／寿命 | 按钮界面、点按防御、持续防御、格挡成功、防御波 |
| B 冲刺 | 冲刺距离、持续时间、冷却 | 按钮界面、冲刺拖尾、起步和结束表现 |
| C 斩击 | 斩击半径、伤害、旋转间隔、长按上限、瞄准移动倍率 | 按钮界面、普通斩击、环形斩击、持续旋转、瞄准提示 |
| A+B | 组合释放规则、组合冷却、该组合专属参数 | 组合按钮、组合过程、释放表现、命中表现 |
| A+C | 闪避判定提前量与容差、反击时间、防御时间、减伤、子弹时间倍率 | 组合按钮、闪避提示、反击阶段、结束防御、子弹时间表现 |
| B+C | 组合释放规则、组合冷却、该组合专属参数 | 组合按钮、组合过程、移动斩击、命中表现 |

共享参数在 Inspector 标明来源，例如“继承按钮 B 的冲刺距离”。需要独立调整时启用覆盖。技能组合管理负责通用拖拽、取消、槽位替换和按钮隐藏，对应技能对象负责自身伤害、阶段与表现。

## Scene 中的 UI

- 把 Canvas 和控件保存在 GameScene。按钮包含背景、图标、文字、冷却遮罩、冷却数字和持续时间环，均可在编辑模式选中。
- 使用 RectTransform 锚点、Canvas 缩放和安全区域适配布局。组合按钮按现有规则替换目标槽位。
- 增加编辑预览，可切换默认、冷却、长按、组合和结算状态。血条、时间、击杀数、摇杆和结算面板可直接在 Scene 编辑。
- 世界特效使用独立 Prefab，在玩家挂点或运行时特效容器下生成。

## 实施与验收

1. 将现有序列化参数迁移到对应组件，核对场景中的当前取值和玩法。
2. 建立 Canvas 控件，接入原有输入、拖拽、冷却和组合逻辑。
3. 拆分技能外观和音效，加入编辑预览。
4. 将 Arena 收敛为初始化和引用连接入口，移除重复参数和旧的 OnGUI 界面。

验收时，选中「按钮 A+C／功能」应只看到该组合的玩法参数，选中「按钮 A+C／外观／反击阶段」可单独调整该阶段表现。在编辑模式下，应能直接在 Scene 中选中按钮、血条与摇杆。
