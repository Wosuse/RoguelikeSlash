# M6 P0～P4 开发与调试

本批完成到 P4：属性、结算、暂停、经验金币、升级构筑、武器背包以及飞镖/飞刀/弓箭 +0～+3。P5 商人/ShopScene、P6 存档与手机性能验收不在本批。

## 场景分工

打开 `Assets/Game/Scenes/GameScene.unity`，在 Arena 下查看：

| 子物体 | 职责及可调整内容 |
|---|---|
| 系统/时间与暂停 | `RunClock`，多原因暂停；子弹时间仍由原技能系统提供世界时间倍率 |
| 系统/M6调试 | `RunDebug`，运行时按钮：加经验、金币、属性、获取武器、加熟练、生成怪物、清冷却、重开 |
| 玩家/功能 | 原移动配置仍控制基础移速；自动射击间隔改到各武器资源 |
| 玩家/功能/角色属性 | `RunStats`，基础属性、上限、护盾容量/周期；运行时只读有效属性与碎片来源 |
| 玩家/功能/武器背包 | `WeaponInventory`，武器定义、重复武器收益；运行时装备/等级/弹丸/方向读数 |
| 玩家/功能/自动武器 | `AutoWeaponController`，发射、弹丸池、整轮预算、方向偏角、运行时数量 |
| 玩家/外观/护盾表现 | 护盾环材质、颜色、半径、线宽、生成音效 |
| 战斗/伤害结算 | `DamageResolver`，攻击/暴击统一结算，实际生命损失才结算普攻吸血 |
| 战斗/流血状态 | `BleedStatusController`，每目标独立层数/持续时间/tick |
| 敌人/奖励档位与掉落 | 四档权重、经验、金币和生命倍率；与攻击行为独立；掉落纹理、材质、颜色和磁吸 |
| 成长/经验与升级奖励 | 经验曲线倍率、三片起始等级、品质概率、能力/碎片池、价格倍率 |
| 成长界面 | 独立 Canvas；状态、背包、属性及升级选择均为场景 UI，可在编辑器展开选中 |
| 运行时/自动武器弹丸、经验与金币 | 动态实例容器，不保存本局状态到配置资源 |

场景补装或引用修复：`Tools > Arena > M6 > 安装或修复场景引用`。重复运行保留已有配置资源和已存在 UI，不重置调参。

## 配置资源

`Assets/Game/Data/M6`：三份 Weapon、六张 Card、十九份 Shard。

- 武器：间隔、速度、射程、旋转半径/tick、流血tick、弓箭减速、子箭射程/索敌、障碍物层、图标、纹理、材质、颜色、尺寸和发射/命中音效。
- 能力卡：弹丸、方向、共享熟练、三种武器获取；图标、说明、选择音效可换。
- 碎片：六种属性的银/金版本，七种彩色属性；数值、图标、获取音效可换。没有敌方护盾时护盾击破卡不入池。
- 弓箭障碍物层默认空；当前场景没有要求新增墙体。将实际墙体 Collider2D 所在层填入该项后，主箭撞墙也会分裂，勿将玩家所在层算作墙体。

## 本批规则

- A 点按原始 CD 2.5s，其余基础技能 8s、融合 12s；急速在技能结束时计算，已开始的冷却不追溯属性变化。
- 技能 Pending、Holding、Active 及派生波/剑气未结束时，不发射新普通攻击。已经离手的弹丸和已施加的流血正常结束，不因释放技能被删除。
- 初始飞镖，升级奖励选择能力卡或锻体。原型设 2～5 级获得 2 片、6 级起 3 片；阈值可调，无品质保底。品质权重默认银 70 / 金 25 / 彩 5。
- 三种武器共用熟练度，累计 1/3/6 点升到 +1/+2/+3。重复武器默认 +1 点，可配置。满级不再抽到熟练卡或已拥有武器卡，仍能抽未拥有武器。
- 背包中切换已获得武器，保留弹丸/方向升级与熟练进度，也保留射击倒计时，避免连续换装刷出手。
- 护盾首片解锁后 15s 生成 5 点；周期补满、不累计、破盾不重置计时。容量碎片前置严格过滤。暴伤片 +15 个百分点。
- 碎片价格基线由普通怪金币 ×20 导出；商店购买入口留到 P5。
- 飞镖返程造成 20% 攻击力伤害，再乘弹丸伤害系数，同一枚返程飞镖每个敌人最多命中一次，第二次旋转中心固定在到达位置；飞刀流血默认 0.5s/tick，刷新不重置 tick，每次结算读取当前角色属性，武器等级随施加流血记录。
- 弓箭同一轮共享目标命中计数，重复命中依次乘 .65、最低 .1；子箭继承主箭发射序号系数并满速生成，不递归分裂。
- 普攻完整轮次先预留弹丸预算，避免只射出一部分。预算不足延后出手，运行时显示阻塞次数，默认预算 512。

## 推荐调试步骤

1. 运行 GameScene，选 `系统/M6调试`，加 40 经验，测试升级路径与恢复战斗。
2. 增加大量经验测试连续升级；每次奖励排队，不重复、不丢失。
3. 获取飞刀/弓箭，打开游戏左上武器背包切换；再次获取同一武器观察共享熟练。
4. 熟练加至 6，验证三武器所有专属阶段；用能力卡增加弹丸和方向。
5. 按住各基础/融合技能，观察“自动武器”的活跃数和新弹丸：不应出现新的发射轮次。
6. 增加护盾生成属性，验证等待15秒、初始5点、容量片解锁；添加急速观察各技能 CD。
7. 重开后核对等级、经验、金币、属性、护盾、熟练、武器、DOT和掉落物全部清空。

`Tools > Arena > M6 > 运行集成验证（运行模式）` 会重置本局并执行断言，适合开发验证。结果写入项目根目录 `M6-validation.txt`（已忽略，不上传生成文件）。测试涵盖属性公式、奖励与钱包、满级过滤、实际技能停射、飞镖穿透/旋转、流血完整周期、弓箭九主箭/54总弹丸、吸血实际伤害与死亡去重。

本批通过 Unity 编译与 70 项集成断言；同时检查运行 HUD 和奖励界面截图。此记录不等于抖音真机帧率测试，也未重新导出抖音包。
