# 卡牌实验室与调参

## 场景

正式游戏为GameScene，调试为CardLabScene。通过菜单Tools → Arena打开。两个场景的布局和组件参数独立；技能动画配置引用同一份资产。

CardLab保留为日常开发工具。历史自动验证脚本和独立M6Validation工程已移除。

## 操作

1. 运行CardLab，展开左侧调试栏。环境页控制自动生怪、敌人行动、玩家免伤、普通攻击和射程圈。
2. 默认不自动生怪。摆放木桩或开启生怪，才能观察普通攻击命中；动画装配台的预览角色不是攻击目标。
3. 卡牌页可搜索，＋1/－1调整获得次数。点击栏目展开说明，并在Inspector选中对应配置；Inspector需取消锁定。
4. 组合页应用预设会清空已有卡，不累计叠加，保留木桩位置。控制台Inspector可另存当前卡牌组合。
5. 支持单桩、成排木桩、布局木桩以及点击放置/移除。Scene视图可拖动布局手柄。滚轮在调试栏内滚动列表，在战斗区域调整摄像头视野。

## 参数入口

| 内容 | 位置 |
|---|---|
| 基础移速 | 玩家功能上的ArenaMovementTuning；100对应5单位/秒 |
| 普攻 | 战斗/普通攻击/V06Attack；Range默认6；Sprite、Color、Size控制弹丸外观 |
| 卡牌效果与图标/音效/特效 | 成长/强化卡配置下对应V06Card；效果调参按卡牌展示 |
| 闪距离和斩范围、伤害、冷却、音效 | 战斗/主动技能/V06Skills |
| 动画与剑气 | DefaultSkillAnimations.asset，见技能动画装配文档 |
| 山贼动画 | 敌人/追击敌人/山贼动画上的EnemyAnimationProfile |

踢踏舞仅普攻每轮首次命中叠一层，每层移速和攻速各加1%，默认上限100。后续普攻命中刷新5秒倒计时；生命受伤或倒计时结束清层，护盾完全吸收/免伤不清。斩、剑气、DOT不能叠层或刷新计时。

## 保存配置

在Play中改好参数后点击「保存当前配置」，再退出Play。组件调参、卡牌各阶段数组及素材引用会写回当前场景。不会保存当前生命、已获得卡牌次数、踢踏舞层数、冷却、敌人或弹丸等局内状态。

卡牌组合需要使用「另存当前卡牌组合」单独保存。动画等.asset资源本身独立于场景，两个场景共用时修改会共同生效。

手工布局和子物体以场景为准。已移除旧场景重建/修复工具，日常直接编辑现有场景。

## 场景分工

Arena下的战斗集中放主动技能、普通攻击、元素结算和伤害结算；成长集中放经验金币、构筑规则与生存、强化卡配置。系统、玩家、敌人、运行时、武器和两套既有界面各自保留职责。运行时的敌人/弹丸/金币容器看起来为空，但会在游戏中接收实例，不是重复对象。

当前46张卡已从CardLab同步至GameScene。蓄势、踢踏舞、写意、月牙、涟漪、离别赠礼的说明读取配置；数值变化后，奖励简述、详情和实验室说明会按各自用途显示。旧A/B/C、按钮融合和旧自动武器/流血执行器已移除，武器背包和角色面板的数据功能保留。
